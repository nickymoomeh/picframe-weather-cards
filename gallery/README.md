# Distance-readable weather cards

Synthetic illustrations, not the user's captured forecast. The minimal comparison recreates Saltwood at 09:01 on Saturday 31 October, 10°C and clear sky; other values are simulated. Both sides use identical data, time and font. Before is the renderer from `18b3de0`. Original icons/backgrounds are MIT licensed.
